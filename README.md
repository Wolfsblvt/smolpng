# smolpng

**Make images smol.**

Local-first image compression for humans, scripts, and agents. Born because an icon upload rejected a perfectly ordinary PNG; designed so the next image takes one action rather than another trip through an upload website.

**Private implementation in progress.** This initial foundation is not yet an executable candidate. The first usable path will be a deterministic PNG command, followed by keyboard-driven everyday use and version-bound Agent Skill installation. No release, installer, or package-manager entry has been published.

An open-source project from Wolfsblvt Works.

## Destination

One engine serves the keyboard interface, background drop workflow, scripts, and agents. PNG comes first; PNG and JPEG are the selected 1.0 destination. Auto is local by default, originals survive, and a target such as `10KiB` means at most 10,240 bytes—not approximately nearby.

The [Vision](docs/VISION.md) preserves the complete destination. [Direction](docs/DIRECTION.md) distinguishes the current implementation frontier; [Development](docs/DEVELOPMENT.md) will carry the exact usable commands as they become real.
