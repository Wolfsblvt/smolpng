# Security reporting

## Meaning

This policy owns private vulnerability reporting for the public smolpng source repository. The project is pre-release; no independent security audit, supported release series or response deadline is promised.

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/Wolfsblvt/smolpng/security/advisories/new). Wolf receives these reports as the repository maintainer. Please keep exploit details, private images and credentials out of public Issues.

Include the source commit or executable version, operating system, reproduction steps and the concrete consequence. A minimal generated image is preferable to personal media. Ordinary compression defects belong in Issues unless they expose a security consequence.

The maintained [security boundaries](docs/SECURITY.md) explain the trusted-user model, external optimizers, atomic output, managed installation and native integration limits. Source publication is not a claim of a signed release or qualified public upload service.
