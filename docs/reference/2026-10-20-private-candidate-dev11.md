## Windows amd64 evidence

On Windows 11 25H2 amd64, the extracted candidate passed all 63 native PNG/JPEG compression checks with the recorded local optimizer identities. The separate 26-command dependency/Agent Skill lifecycle passed in an isolated user home. The candidate also passed 13 update/recovery operations, four output-lock cases, two deadline/retry cases, three hidden terminal flows, and cancellation during active OxiPNG work. These are the boundaries those local observations exercise; they do not prove graphical desktop interaction or client Skill reload.

The exact-candidate integration installer preview returned five targets: interactive and Auto Start-menu launchers, Auto and interactive desktop shortcuts, and a Send To shortcut. All five exact target paths were absent before installation. The candidate installed them with an isolated portable state root; status read back each entry as `current`, with version `0.3.0-dev.11`, expected executable, arguments and terminal behavior. A repeat install succeeded. After one test shortcut was modified, status reported `modified`; removal returned exit 5 and preserved that target. The exact original shortcut bytes were restored and their SHA-256 matched. Removal then returned exit 0, status reported zero entries, and all five paths were absent. No shortcut or launcher was activated and no GUI or clipboard was used.
